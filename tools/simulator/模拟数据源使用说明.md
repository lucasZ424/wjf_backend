# HTSG 模拟数据源 使用说明

本包在装 HTSG 的同一台电脑上，起一个独立的模拟现场（Modbus 与 OPC UA 服务，按模拟通道分配发出数据），供没有现场设备时演示和测试，并可手动触发一个场景。它只发数据，不写任何真实设备，也不改后端程序或数据库。本包**自带运行环境**，解压到哪里都能用，不用装 Python。版本与构建来源见 `VERSION.json`；须与发布包版本相同。

## 1. 核对

在本包目录里打开 PowerShell，运行 `powershell -ExecutionPolicy Bypass -File .\verify.ps1`，显示“校验通过”再用。

## 2. 让后端连模拟现场

安装发布包时，用本包里的 `production.json` 作为配置：把它拷到发布包文件夹旁边，或在安装程序提示时把它拖进窗口（见《安装与运维说明》第1、2节）。它是正式模式：点表与数据源地址指向本机模拟服务，项目名称、存储路径等与发布包的生产基础配置相同，页面不显示“模拟数据”字样。

## 3. 启动模拟现场

双击其中一个（启动后这个窗口要一直开着，关掉即停止）：

| 入口 | 用途 |
| --- | --- |
| **1-启动模拟现场（演示）** | 给人看：负荷、流量、压力、壁温、应变随负荷与局部热负荷联动，曲线变化明显（壁温约每两三秒动一位） |
| **1-启动模拟现场（稳态）** | 做长时测试：同一个机组模型，但按真实机组的节奏慢变——负荷平稳时壁温一两分钟才动 0.1 ℃，全场平均每秒只有约 3 个点有变化 |

两档的物理关系、场景和越限完全相同，只是数据变化的快慢不同。数字是演示设定，不是真实机组的保证值。

第一次启动时生成控制令牌，存在 `sim\.local\simulation-secret.txt`（不打印，不要外传）。模拟现场先起、后端先起都可以：后端连不上时会自己按间隔重连。关掉模拟现场窗口，后端随即显示断连，这本身也是一种异常演示。

## 4. 触发场景

双击 **“2-触发场景”**，按编号选一个，回车。一次只触发一个场景，到时自动回到基线；再触发一个会替换正在进行的。当前有：

- 回到基线
- 工艺场景：变负荷（12 MW/min 降到 510 MW、保持、升回，共 20 分钟）；测点01局部超温（10 分钟，外壁温度、内外壁温差负向、应变越限，结束后回落）；超负荷（升到 690 MW，主汽压力与主汽流量越限，负荷不到 693 MW 高限，共 20 分钟）
- 故障场景：测点01内壁温度传感器极端值、质量变坏、数据冻结、断开 Modbus、断开 OPC UA

也可以在本包目录的 PowerShell 里直接按名字触发：`.\runtime\python.exe sim\sim.py trigger freeze`（`sim.py list` 列出场景名）。

## 5. 注意

- 模拟现场不随开机自动启动，也不由看守程序拉起；断电重启后要再双击第3节的入口。
- 改回真实设备时，用点表工具生成新的 `production.json`，按《安装与运维说明》第5节“改点表或阈值”替换配置；本包可以删掉。
