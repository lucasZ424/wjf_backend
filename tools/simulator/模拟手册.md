# HTSG 模拟手册

用模拟数据源包在一台电脑上搭起“模拟现场＋HTSG”，用于给客户演示和做测试；用完后用包里的清除工具把模拟安装、数据、数据库实例、服务和端口全部去掉，**不让模拟数据留在现场电脑上**。版本见 `VERSION.json`，须与发布包相同。

## 1. 包里有什么

| 入口 | 用途 |
| --- | --- |
| 1-启动模拟现场（演示） | 给人看：负荷、流量、压力、壁温、应变随负荷与局部热负荷联动，曲线变化明显（壁温约两三秒动一位，全场每秒约 85 个点有变化） |
| 1-启动模拟现场（稳态） | 做长时测试：同一个机组模型，按真实机组的节奏慢变（负荷平稳时壁温一两分钟才动 0.1 ℃，全场每秒约 3 个点有变化） |
| 2-触发场景 | 按编号选一个场景触发，复现变负荷、越限、断连等用例 |
| 3-清除模拟安装 | 去掉模拟安装产生的一切（第5节） |
| `production.json` | 让 HTSG 连模拟现场的配置，安装时交给发布包的安装程序 |

两档的物理关系、场景和越限完全相同，只是数据变化快慢不同。模拟机组按 660 MW 超超临界直流炉、600 MW 参考工况构造，测站当作水冷壁受热管段（外壁高于内壁）；数字是演示设定，不是真实机组的保证值。

## 2. 部署模拟

需要：发布包 `HTSG-…`、本包 `HTSG-SIM-…`（同一版本），一台 Windows 电脑，两块本地盘（正常库、应急库各一块；应急库所在盘至少留 100 GiB）。

1. 两个包都拷到电脑上解压，各自在包目录里运行 `powershell -ExecutionPolicy Bypass -File .\verify.ps1`，显示“校验通过”。
2. 把本包的 `production.json` 拷到发布包文件夹旁边（同一目录）。
3. 双击发布包里的“安装.cmd”，授权后按提示选两块盘，等到“安装完成”（详见发布包《安装与运维说明》第2节）。管理员初始口令在 `D:\HTSG\app\.local\initial-credentials.json`。
4. 双击本包的“1-启动模拟现场（演示）”或“（稳态）”。这个窗口要一直开着；关掉即模拟现场停止（后端会报断连，这本身也是一种异常演示）。模拟现场与后端谁先起都可以。
5. 浏览器打开 `http://127.0.0.1:8000`，用 admin 和初始口令登录；“系统自检”页两个数据源“数据有效”即连好。

模拟现场不随开机启动；电脑重启后后端与数据库自己起来，模拟现场要再双击第4步的入口。

## 3. 复现用例

双击“2-触发场景”，按编号选一个回车。一次只生效一个场景，到时自动回到基线；再触发一个会替换正在进行的。下表的“应看到”是 2026-11-01 在本机实跑（演示档）的结果。

| 场景 | 持续 | 应看到 | 复归 |
| --- | --- | --- | --- |
| 变负荷 | 20 分钟 | 负荷按 12 MW/min 降到约 510 MW、保持约 5 分钟、升回；流量、压力、给水温度、壁温、温差、热应力随之平滑变化。**不产生任何越限** | 场景结束回到基线摆动 |
| 测点01局部超温 | 10 分钟 | 约 2.5 分钟后测点01的内外壁温差“故障已确认（低）”，随后外壁温度（高）、应变（低）也确认；热应力页该温度对曲线变橙；其他测点不动。共 3 条故障记录 | 场景结束后约半分钟内全部复归 |
| 超负荷 | 20 分钟 | 负荷升到约 690 MW（**不到 693 MW 负荷高限，负荷本身不报**）；主汽流量约 2.5 分钟后、主汽压力约 6 分钟后“故障已确认（高）”；壁温不越限。共 2 条故障记录 | 降负荷途中复归 |
| 测点01温度传感器极端值 | 30 秒 | 测点01内壁温度标“极值”；它的温差、热应力不可用，热应力峰值不可用（峰值要求全部温度对有效）；不产生故障记录 | 场景结束即恢复 |
| 质量变坏 | 20 秒 | 测点01内壁温度、电桥01 标质量坏；依赖它们的量不可用 | 场景结束即恢复 |
| 数据冻结 | 20 秒 | 数据仍有效，**不误报断连** | — |
| 断开 Modbus | 20 秒 | 约 10 秒后 Modbus 数据源报断连，电桥与应变不可用；OPC UA 不受影响 | 自动重连，恢复“数据有效” |
| 断开 OPC UA | 20 秒 | 约 6 秒后 OPC UA 数据源报断连，温度、过程量不可用；Modbus 不受影响 | 自动重连 |

越限持续满 5 秒才确认。历史查询页可回看各场景期间的曲线与故障记录（回放图中数值超出限值的段画橙色）。

以下几项不靠场景，直接操作：

| 做法 | 应看到 |
| --- | --- |
| 关掉模拟现场窗口，5 分钟后再双击启动 | 两个数据源都报断连；起来后自动恢复 |
| 在 `D:\HTSG\app\.local` 下建空文件 `STOP`，等后端停下后删掉 | 后端正常停止；删掉后 5 分钟内看守程序把它再拉起，开始新的一次运行 |
| 任务管理器里结束后端的 python 进程 | 5 分钟内被拉起，上一次运行在重启时收尾 |
| 正常库所在盘到 95% | 写入目标变为“应急库”，各页有提示，采集照常 |

## 4. 长时运行测试（14 小时）

用稳态档，只看“不崩溃”（项目硬规则：一年运行不崩溃），其间穿插第3节的异常操作。

1. 电脑设为接通电源时“从不”睡眠，暂停 Windows 更新；测试期间不动电脑。
2. **开始时间在上午 10 点到晚上 12 点之间**：换桶要“本地日期变过且当前桶已运行满 12 小时”，这个窗口内开始，14 小时内必换一次桶（“系统自检”页桶号变化即测到）。
3. 按第2节部署，模拟现场用“1-启动模拟现场（稳态）”。
4. 每 5 分钟记录一次进程资源，结束时看内存、句柄、线程是否只涨不落（PowerShell 窗口一直开着）：

```powershell
while ($true) { Get-Process python | Select-Object @{n='time';e={Get-Date -Format s}},Id,@{n='MB';e={[int]($_.WorkingSet64/1MB)}},HandleCount,@{n='Threads';e={$_.Threads.Count}} | Export-Csv D:\proc.csv -Append -NoTypeInformation; Start-Sleep 300 }
```

5. 前 6 小时内穿插第3节的场景与直接操作，逐项记下实际表现。
6. 1 小时后看“系统自检”页正常库的占用和增长，推算到 95% 的时刻。

**要测“转应急库”**：稳态档写入很少（全场每秒约 3 个点），正常库盘就算只有一两 GB 也不会在 14 小时内到 95%。要测这一项，正常库得放在一块很小的虚拟盘上，大小按实测增长定：先在虚拟盘上装好跑 1 小时，看正常库每小时增长多少，再按“已用＋增长×希望触发的小时数＝盘容量×95%”重建一块合适大小的虚拟盘，清除后重装。也可以单独用演示档（写入量约为稳态的 30 倍）短时间验证这一项。虚拟盘在管理员 PowerShell 里用 diskpart 建：`create vdisk file="D:\HTSG-vhd\primary.vhdx" maximum=<MB> type=expandable` → `attach vdisk` → `create partition primary` → `format fs=ntfs quick` → `assign letter=V`；虚拟盘重启后不会自动挂回，测试中途不要重启。

## 5. 清除模拟安装

演示或测试结束、离开现场电脑之前，**必须清除**：

1. 关掉模拟现场窗口（不关也行，清除工具会停掉它）。
2. 双击本包的 **“3-清除模拟安装”**，授权。它先列出要清除的每一项，输入“清除”回车才动手。
3. 它依次：放 STOP 让后端正常停下 → 删开机任务 HTSG-Backend → 停止并删除两个数据库服务 → 删两块盘上的数据目录（`<盘>\HTSG\primary`、`emergency`，含数据库实例与全部模拟数据）→ 删程序目录 `D:\HTSG\app`、数据库软件 `D:\HTSG\pgsql`、安装日志 → 停模拟现场、删它的控制令牌。最后逐项核对：端口 8000、55440、55441、14840、14841、15020 都不再监听，服务、任务、目录都不在，才显示“清除完成”。
4. 手动删掉两个包的文件夹（清除工具正在运行，删不了自己所在的包）。测试用过虚拟盘的，在 diskpart 里 `select vdisk file=…` → `detach vdisk`，再删 `.vhdx` 文件。

安全与可靠：

- 它**只清除模拟安装**：已安装配置的数据源与本包 `production.json` 不一致（即真实现场的配置）时拒绝，什么都不动。
- 数据目录里有本程序以外的文件时不删那一个目录，列出来请人工查看。
- 中途出错或断电，再双击一次即可：动手前清单已存在本包 `sim\.local\cleanup-plan.json`，程序目录没了也能照它接着清。
- 只想先看会删什么：`.\runtime\python.exe sim\cleanup.py --dry-run`。装在别的根目录时加 `--root E:\HTSG`。

## 6. 常见问题

- **页面上曲线是红色一段段的**：浏览器标签页切到后台很久，浏览器降低了页面读取频率，期间页面没有读到数据，画成“无数据”；切回前台后正常。后端数据本身是连续的，历史查询页可以看到。
- **触发场景提示连不上模拟现场**：模拟现场窗口没开或已关，先双击“1-启动模拟现场”。
- **超负荷时负荷没报警**：负荷高限是 693 MW，场景只升到 690 MW，设计如此；报警的是主汽压力与主汽流量。
