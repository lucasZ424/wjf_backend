# HTSG 点表工具 使用说明

把现场点表从 Excel 转成后端的配置文件 `production.json`。本包自带运行环境，**任何一台 Windows 电脑解压即用**，不用装 Python，也不用连网。版本见 `VERSION.json`，须与发布包相同。

## 1. 核对

在本包目录里打开 PowerShell，运行 `powershell -ExecutionPolicy Bypass -File .\verify.ps1`，显示“校验通过”再用。

## 2. 生成空白点表

双击 **“1-生成点表模板”**，本目录里出现 `点表.xlsx`。已经有 `点表.xlsx` 时不会覆盖它（以免盖掉填好的表）；要新的空白表，先把旧的改名或挪走。

空白点表不预填任何点：订阅什么就填什么。也可以用自己整理的 Excel，只要工作表名和表头与空白点表相同。

## 3. 怎么填

“数据源”表：填两个数据源的连接（Modbus 网关的主机与端口、OPC UA 服务器的端点），要用的数据源“启用”填“是”；编号不要改。

“Modbus点”“OPC UA点”两张表，**每行一个要订阅的点**：

| 列 | 怎么填 |
| --- | --- |
| 类别 | 从下拉里选：内壁温度、外壁温度、电桥、机组负荷、水冷壁流量、主汽流量、主汽压力、给水温度、再热温度、工质温度、炉膛负压、其他 |
| 温度对号 | 只给内壁、外壁温度填，正整数。同一个号的一内一外是一对 |
| 显示名称 | 现场位号或中文名，页面上显示它；不填则按类别和编号起名 |
| 备注 | 随便写，不进配置 |
| 数据源 | 与“数据源”表的编号一致 |
| 地址／NodeId | Modbus 点填寄存器地址（及从站号、数据类型等），OPC UA 点填 NodeId。留空表示这一行暂不接入 |
| 单位、上下限、回差、极值 | 可以不填：按类别取默认值（例如壁温上限 490 ℃）。要去掉某个默认值，在那一格填“无”。“其他”类没有默认值，单位必填 |

工具据此生成（不用填、也不用管内部编号）：

- 每一对内外壁温度：内外壁温差、热应力估算；全部温度对再生成一个热应力代理绝对峰值。只接入了一侧的温度对照常接入那一侧，不生成这两项。
- 每一路电桥：换算应变、应变变化量，以及“水冷壁应变场”页上的一个测点色块（名称用显示名称，位置自动排）。
- 过程量各类最多一个；“其他”类的点照常接入、可在通信页和历史页查看，不生成派生量。

## 4. 生成配置

把填好的点表**拖到“2-生成配置”上**（或把它放在本目录、命名为 `点表.xlsx` 后双击“2-生成配置”）。

- 通过：本目录里出现 `production.json`，窗口里列出接入了多少点、哪些行没接入、哪些类别用了默认值、生成了哪些派生量。旧的 `production.json` 会改名留底（`production.年月日-时分秒.json`）。
- 不通过：窗口里按“表名 第几行 哪一列”列出错误（例如类别没选、温度对号重复、同一类过程量填了两个），不生成文件，旧的 `production.json` 不动。改正点表后再拖一次。

## 5. 交给安装

把 `production.json` 拷到发布包旁边（与发布包文件夹放在同一目录），双击发布包里的“安装.cmd”；或在安装程序提示时把它拖进窗口。已经装好的系统要换配置，按《安装与运维说明》第5节“改点表或阈值”。
