# HTSG 点表工具 使用说明

把现场点表从 Excel 转成后端的配置文件 `production.json`。本包自带运行环境，**任何一台 Windows 电脑解压即用**，不用装 Python，也不用连网。版本见 `VERSION.json`，须与发布包相同。

## 1. 核对

在本包目录里打开 PowerShell，运行 `powershell -ExecutionPolicy Bypass -File .\verify.ps1`，显示“校验通过”再用。

## 2. 生成点表模板

双击 **“1-生成点表模板”**，本目录里出现 `点表.xlsx`。已经有 `点表.xlsx` 时不会覆盖它（以免盖掉填好的表）；要新模板，先把旧的改名或挪走。

交现场填写：接入的点填 Modbus“地址”或 OPC UA“NodeId”，不接入的行留空（这是正常情况，不报错）。内部编号不要改。

## 3. 生成配置

把填好的点表**拖到“2-生成配置”上**（或把它放在本目录、命名为 `点表.xlsx` 后双击“2-生成配置”）。

- 通过：本目录里出现 `production.json`，窗口里逐条列出去掉了什么（未接入的点、依赖它们的派生量与界面测站等）。旧的 `production.json` 会改名留底（`production.年月日-时分秒.json`）。
- 不通过：窗口里按“表名 第几行 哪一列”列出错误，不生成文件，旧的 `production.json` 不动。改正点表后再拖一次。

## 4. 交给安装

把 `production.json` 拷到发布包旁边（与发布包文件夹放在同一目录），双击发布包里的“安装.cmd”；或在安装程序提示时把它拖进窗口。已经装好的系统要换配置，按《安装与运维说明》第5节“改点表或阈值”。
