# 轻量版本默认极值阈值

版本：2026-10-08。依据用户授权，由 AI 根据当前模拟端口、单位、场景和工程常识设定，已写入 `config/research-sim.json`，不再等待用户提供默认值。

这些是本项目用于识别明显异常量级的科研/调试默认界限，不是设备实际量程或保护定值。外部资料只用于核对量级；表中具体余量由 AI 选择，并非从厂家文件直接引用。实际端口资料明确后可按部署配置修改，不增加在线调参功能。

<a id="extreme-rules"></a>

## 2 判定及运行行为

- 仅当 `x < extreme_low` 或 `x > extreme_high` 标记 extreme；等于界限不触发。
- 不采用正常值倍数，不因过零、符号变化、数值长期不变或突变本身判坏。
- 判定在源点 scale/offset 换算后的工程单位上执行；Bridge 此时仍为 mV/V，随后才按 x×1000/6 计算微应变。
- 原始极端值保留原数值、接收时间和协议质量，另存 extreme 标记；不得截断、替换成 0 或覆盖原值。当前页面显示 EXTREME，历史曲线保留该点并标注。
- 极端输入使依赖结果为 `EXTREME_INPUT`、不输出数值。若派生结果本身超出其极值范围，保留该结果并标记 extreme，下游计算不继续使用。
- 极值标记即时生效，极端值不形成普通工艺故障；故障计时与回差以[终版设计](../HTSG_V1_终版设计_v1.0.md)第8节为准。
- 极值边界与普通low/high、hysteresis_low/high分别配置：先判断数据有效性，再对有效值判定普通故障，两套规则互不替代。普通阈值待按终版实施，不以当前JSON缺字段为取消依据。
- 端口解码失败、空值、非有限数和连接失败继续如实报告；不由这些技术状态推断死点、跳变或其他设备坏点。

## 3 量级参考与验证

三菱重工公开的贯流锅炉规格列有约 600/620 °C 蒸汽温度与最高约 31 MPa 蒸汽压力，用于核对本项目模拟量级；800 °C、40 MPa 仍是本项目主动放宽的默认界限。[厂家资料](https://power.mhi.com/products/boilers/lineup/once-through)

氧量已从本轮 P1/P2/P4 的默认点表移除，旧氧量范围不作为本轮 200 点配额的一部分。新增流量和炉膛负压的基线直接采用参考 HTML，界限是本项目的宽裕模拟默认值。

其余默认值由当前配置的额定功率、信号范围、场景偏移、GF 换算和热模型系数直接推导或留余量，不宣称存在统一工业报警标准。验收用例见 `tests/test_extremes.py`：全部通道及界限等号、合法负值/零值、正常瞬态、极值原值保存与依赖阻断、以及不按源组合拒绝配置。
