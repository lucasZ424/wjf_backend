## 历史依据与验证正文（不作为现行开发规定）

以下保留原实现、模型、审计或验证事实。正文中的“当前”“已确认”“待定”及规则要求均属于原记录日期和旧基线；冲突机制已由上方规定替代，不构成新机制的开发要求或验收结果。现有启动命令仍启动旧版程序。

本轮采用两个温度通道的“受约束热膨胀差代理量”。它能在没有真实材料与结构资料时，验证温差、参数敏感性、趋势和事件回看的全过程。输入可来自模拟现场；测点位置只是示意坐标。模型不要求真实拓扑，也不根据总应变直接认定热应力。

## 物理依据与本项目假设

线性热膨胀给出热应变 `α ΔT`；理想单轴完全约束时，弹性应力的幅值为 `E α ΔT`。DOE 材料科学手册 Module 3 第 3 页给出这一理想关系。[DOE-HDBK-1017/2-93（PDF 第 21 页）](https://www.energy.gov/sites/default/files/2026-04/DOE-HDBK-1017-93_VOL2.pdf#page=21)

NASA 的结构说明同样区分自由膨胀与约束引起的应力，并说明温度分布需要映射到结构模型才能分析结构响应。[NASA/SP-20230004376，Thermal Considerations](https://ntrs.nasa.gov/api/citations/20230004376/downloads/20230004376.pdf)

本项目由此构造的代理公式是：

```text
ΔT = T_inner - T_outer
S_proxy = r × E × α × ΔT
```

`T_inner / T_outer` 是配置中指定的两个温度输入。只有现场证实安装位置后，才能称为真实内外壁温；模拟配置中的配对是研究假设。`r ∈ [0,1]` 是等效约束系数。正值只表示第一个输入温度更高，负值表示第二个更高，不表示真实拉/压应力方向。两个输入同温时代理量为零；这不代表整体受约束均匀加热一定没有应力。

这一步是本项目的建模假设，不是文献给出的锅炉壁面通用解。缺少几何、材料、参考温度、边界约束时，真实三维热应力不可唯一识别。因此先采用可解释的少参数代理模型；当前不能声称它是“最优真实应力估计”、有限元等价结果或剩余寿命计算。后续若取得独立校核数据，由我们拟合约束系数、更新材料参数或替换算法，并保留模型版本与依据。

## 配置与单位

`models` 中定义模型，派生项使用 `operation: thermal_stress` 和 `model_id` 引用；输入必须是两个采用相同摄氏温度单位的通道，输出固定 `MPa`，派生缩放为 1、偏置为 0。常量默认值只是本轮合成实验假设，不代表已经确认的锅炉钢号。

| 参数 | 默认值 | 说明 |
|---|---:|---|
| `young_mpa` | 170000 MPa | 弹性模量，合成研究假设 |
| `expansion_per_k` | 0.0000135 /K | 线膨胀系数，合成研究假设 |
| `restraint` | 0.5 | 等效约束系数，未由现场辨识 |
| `young_relative_uncertainty` | 0.1 | 弹性模量上下扰动 10% |
| `expansion_relative_uncertainty` | 0.1 | 膨胀系数上下扰动 10% |
| `restraint_uncertainty` | 0.2 | 约束系数上下扰动 0.2，截断至 [0,1] |
| `min_temperature_c / max_temperature_c` | −50 / 800 ℃ | 合成实验允许输入范围，不是材料有效性认证 |
| `version / basis / reference_urls` | 版本/文字/链接 | 记录假设与来源；替换参数时同步更新 |

上述温度范围仅防止算法无声外推。常量材料参数不自动随温度改变；缺少现场材料信息时保留这一假设。修改配置需校验并重启，与其他通道配置相同。

## 参数敏感性与结果表达

`parameter_range_mpa` 使用 E、α、r 的上下限组合，返回该单调乘积的最小与最大值；负温差也按数值升序排列。这是所设参数范围内的确定性敏感性包络，不是置信区间，也不覆盖未知拓扑、温度测量误差或模型形式误差。默认区间宽度本身同样是合成实验假设。

例如独立手算：`E=200000 MPa`，`α=0.00001 /K`，`r=0.5`，温差 `10 K`，结果为 `10 MPa`。采用上表扰动比例，包络为 `[4.86,16.94] MPa`；交换两温度，结果 `−10 MPa`，包络 `[−16.94,−4.86] MPa`。

输入有效时计算状态为 `OK`，同时携带 `estimate.qualification=ESTIMATED`、模型版本、完整参数、温差、依据和敏感性范围，随帧保存。`OK` 仅表示本次计算有效，不把估计值升级为实测值。输入缺失、坏质量或超龄时不输出数值；超出模型温度范围显示 `TEMPERATURE_OUTSIDE_MODEL_RANGE`。

自动测试覆盖独立手算、温差反向、同温、自由/完全约束极限、参数区间截断、无效配置、温度适用范围，以及坏质量和陈旧输入不参与估算。现场材料识别与真实结果误差评估不由这些模拟测试代替。
