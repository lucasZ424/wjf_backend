## 历史与证据

[history目录](history/)保存旧设计、旧审核及旧开发说明，供追溯；它们不能取代终版，也不应将其中当时的实现状态视为当前状态。根目录的旧软件边界已移入这里，不再作为当前入口。

代码、配置、脚本和测试仍在仓库原位置。OpenAPI及既有JSON/PNG等证据仍保留在仓库docs目录，历史证据内容未改；本地证据是否纳入版本管理沿用仓库规则。运行及环境入口见[项目README](../README.md)。

以后移动或删除规范文件时，须同时检查Markdown相对链接、tests/test_spec_links.py入口清单、tests/test_fault_thresholds.py规范表读取路径及其他直接引用。规范内容或链接改动后，重新计算终版UTF-8/LF规范化SHA并更新实施方案当前SHA，不改历史摘要。
