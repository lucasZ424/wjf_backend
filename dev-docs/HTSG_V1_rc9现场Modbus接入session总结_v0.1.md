## 2. 现场 Modbus 连接方式

| 项目 | 现场实际 | 依据 |
| --- | --- | --- |
| 协议 | Modbus TCP | 后端按此读到数 |
| 主机 | `192.168.1.99` | 后端按此读到数；现场说明这是电脑自己的网卡，Modbus 服务由 Acheron 提供 |
| 端口 | `501`，8 路共用 | 后端按此读到数 |
| 寄存器类型 | holding（功能码 03） | 同上 |
| 地址 | 第 n 路为 n×100+2，即 102、202 … 802 | 同上 |
| 每路读取数量 | 2 个寄存器 | float32 占 2 个，读出的数值与 Modbus Poll 一致 |
| 数据格式 | float32，字节序 big，字序 little | 对应 Modbus Poll 的 Float CD AB |
| 连接方式 | 一路一条 TCP 连接，每秒读一次 | 配置里一路一个数据源（`mb_field01`…`mb_field08`），后端每个数据源开一条连接 |
| 从站号 | 待确认，见第 7 节 | 全 1 和 1 到 8 两套配置都发给了现场，没有反馈用的是哪一套 |

| 路 | 显示名称 | 安装位置 | 地址 | 页面读数（mV/V，11-09 照片） |
| --- | --- | --- | --- | --- |
| 1 | 01DAQ17983 | 大包右侧水冷壁 | 102 | -0.0625 |
| 2 | 02DAQ17978 | 大包前墙水冷壁右侧 | 202 | -0.0070 |
| 3 | 03DAQ17981 | 大包前墙水冷壁左侧 | 302 | -0.0078 |
| 4 | 04DAQ17986 | 大包左侧水冷壁 | 402 | 0.0464 |
| 5 | 05DAQ17977 | 66米右侧水冷壁 | 502 | -0.0346 |
| 6 | 06DAQ17987 | 66米前墙水冷壁右侧 | 602 | 0.0145 |
| 7 | 07DAQ17984 | 66米前墙水冷壁左侧 | 702 | -0.0234 |
| 8 | 08DAQ17985 | 66米左侧水冷壁 | 802 | 0.0038 |

填地址时要注意：

- 现场习惯说的 40102、40802，减去 40000 才是要填的地址。不能用通用的“减 40001”算法：通用算法得 101，这里实测是 102。
- 现场说每路“从起始位连续读 10 个位”。后端只读前 2 个就够了，电桥值就在这 2 个里。
- 核对地址用 Modbus Poll：Display 菜单勾选 Protocol Addresses (Base 0)，显示格式选 Float CD AB，这时看到的地址就是点表要填的地址。

现场的修改过程（现场文字，只当线索）：Acheron 里每路只能改端口和起始地址，IP 跟着电脑网卡走。第一次设的是 8 个端口 501–508、地址都是 40202，Modbus Poll 只读到第 3、4 路；改成全部 501、地址 40102…40802 后，8 路都能读。

8 条连接共用一个端口已经在现场跑通。合并成 1 条连接没有试过。

还没有验证：断电重启后 Acheron 能不能自己恢复 Modbus 服务。数据都从它来，如果要有人登录才有数据，就和“断电后以最简单的方式重新投入运行”冲突，要在现场实测一次。

## 3. 精简后的 Modbus 点表需填写项

对照 rc9 点表工具的列（“数据源”表 9 列、“Modbus点”表 21 列）和现场实际，逐列确定。

要填的：

| 填写项 | 填几次 | 怎么填 | 现场的值 |
| --- | --- | --- | --- |
| 主机 | 一次 | 提供 Modbus 服务的电脑的 IP | `192.168.1.99` |
| 端口 | 一次 | Acheron 里设的端口 | `501` |
| 显示名称 | 每路 | 传感器位号，页面上显示它 | 见第 2 节 |
| 地址 | 每路 | Modbus Poll 选 Base 0 时看到的地址，不带 40 | 见第 2 节 |
| 备注 | 每路，可空 | 安装位置，只给人看，不进配置 | 见第 2 节 |
| 从站号 | 待定 | 现场用全 1 就不用填（默认 1）；要用 1 到 8，这一列保留或由工具按行号生成 | 见第 7 节 |

不用填，由工具按现场情况写进配置：

| 原来的列 | 固定成 | 原因 |
| --- | --- | --- |
| 类别 | 电桥 | 现场 Modbus 上只有电桥 |
| 数据源（点表）；编号、类型、启用（数据源表） | 工具按行生成 `mb_field01`…，一路一个，启用 | 保持现场跑通的一路一条连接 |
| 单位 | mV/V | 电桥的默认值 |
| 寄存器类型 | holding | 现场实测 |
| 数据类型 | float32 | 现场实测 |
| 字节序 | big | 现场实测 |
| 字序 | little | 现场实测。留空时后端按 big，所以工具必须写明 little |
| 比例、偏移、无效值 | 1、0、无 | 现场不用 |
| 上下限及回差 | 无 | 电桥原始信号没有默认阈值 |
| 极小值、极大值 | -30、30 | 电桥的默认值 |

直接去掉：温度对号（电桥不填，修复轮18 已删）；数据源表里的端点、用户名环境变量、口令环境变量、安全策略（只对 OPC UA 有用，Modbus 行不填）。

用户 2026-11-09 提出，工具要按 Modbus 现场情况只保留必要的填写项。

1. Excel 模板的 Modbus 部分只留第 3 节“要填的”几项。


实施时要注意：

- 接在修复轮18 之后做。`tools/pointsheet/` 下的工具和说明都在修复轮18 的改动里。
- 这是行为变化，按项目测试工作流走全部六步。受影响的用例有 `tests/test_pointsheet.py`、`tests/test_install.py`，说明有《点表工具使用说明》和 `tools/pointsheet/README.md`。
- 后端不用改。字序的默认值不动，由工具写成 little。
- OPC UA 表不在这次范围内。模拟数据源包不经过 Excel，不受影响。

清单外，待用户确认：地址大于等于 40000 时工具给出提醒。这次读错的直接原因是 40102 这种写法被原样放行。
