# 点级热应力估算模型 v2

<!-- current-contract: 2026-11-05 -->
现行规定以[终版设计](HTSG_V1_终版设计_v1.0.md)为准。
<!-- /current-contract -->

本文公式、参数与结果表达是终版第18节索引的有效规定。修复轮18（用户 2026-11-05 定）起，壁温不分内外壁，热应力改由电桥的换算应变算出，取代此前按内外壁温差的代理模型。

<a id="thermal-formula"></a>

## 公式与假设

```text
stress (MPa) = E (MPa) × strain (με) × 10⁻⁶
```

`strain` 是换算应变（GF=6、全桥 N=1，见终版第3.1节）。每路电桥一路应力，全部应力再取一路绝对峰值（保留符号）。

这是估算，不是实测，也不是结构解：

- 换算应变没有做温度补偿，是总应变，其中不全是热应力造成的；
- 假定单轴弹性，不考虑几何、边界约束和多向应力；
- `E` 取常数，不随温度变化。

符号沿用换算应变的符号；拉、压方向取决于现场电桥接法，现场未核实前不作判断。不声称是有限元等价结果，也不用于剩余寿命计算。

<a id="thermal-parameters"></a>

## 配置与单位

`models` 中定义模型，派生项使用 `operation: elastic_stress` 和 `model_id` 引用；输入必须是一路单位为 `με` 的量，输出固定 `MPa`，派生缩放为 1、偏置为 0，否则配置校验拒绝。

| 参数 | 默认值 | 说明 |
|---|---:|---|
| `young_mpa` | 170000 MPa | 弹性模量，合成假设，现场钢号确认后替换 |
| `version / basis / reference_urls` | 版本/文字/链接 | 记录假设与来源；替换参数时同步更新 |

修改配置需校验并重启，与其他通道配置相同。

<a id="thermal-results"></a>

## 结果表达

输入有效时计算状态为 `OK`；`OK` 仅表示本次计算有效，不把估计值升级为实测值。换算应变缺失、无效或判极值时不输出数值。归档只存结果的值与状态，不存计算依据（第10节）。

极值界限 ±850 MPa，对应应变极值 ±5000 με（E=170 GPa），应变有效时应力不会先判极值。不设越限：应力与应变成正比，设了只会重复应变的记录。

手算：`E=170000 MPa`，应变 `690 με`，结果 `117.3 MPa`；应变 `-100 με`、`E=200000 MPa`，结果 `-20 MPa`。
