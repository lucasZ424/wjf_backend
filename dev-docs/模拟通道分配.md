# 模拟通道分配（2026-10-08）

按用户要求，默认模拟运行满 222 个 OPC UA 订阅点，用于业主上限联调。订阅点指 monitored item/NodeId，不是建立 222 条连接或 222 个 Subscription 对象。点表位于 `config/research-sim.json`，均为部署配置，普通用户不在线增删改。

| 类别 | 数量 | ID / 含义 |

| OPC UA 壁温 | 215 | temp_wall_001…215，不分内外壁（修复轮18） |
| OPC UA 过程量 | 7 | 下表所列过程量 |
| 原始输入合计 | **230** | 8 Modbus＋222 OPC UA |

| 应变变化量 | 8 | strain_change_01…08，同连接段内连续计划轮次的有效换算应变之差，με |

| 热应力绝对峰值（保留符号） | 1 | thermal_stress_peak，对 8 路估算结果取绝对值最大者并保留符号；绝对值相同取通道顺序在前者（修复轮15） |

215 路壁温分布在原型的 8 个模拟段 H1…H8（模拟对象为水冷壁受热管段）。编号 i 的段号为 `(i−1)%8+1`；例如 001、009、017… 属于 H1。前 8 路与当前 8 个应变展示位置对应，其余可在热应力页和历史页选择。这是填满容量的模拟配额，不声称现场确有这些位置。

## 2 对照原型第 1、2、4 页

依据为 `htsg_hmi.html` 中 P1/P2/P4 及 renderP1/renderP2/renderP4 的实际字段；原型的 16 路应变和 50 Hz 文案由用户规定的 8 路、1 Hz 覆盖。

| OPC UA 过程点 | 工程量 | 模拟基线（参考工况 600 MW 下的值，随负荷联动见修复轮15） | 默认极值范围 | 原型用途 |
| --- | --- | --- | --- | --- |
| load_mw | 机组负荷 | 600 MW | -20～800 MW | P1/P2 过程量、P4 负荷关系 |
| feedwater_flow | 给水流量 | 1850 t/h | -50～3000 t/h | P1/P2 过程量 |
| main_steam_flow | 主汽流量 | 2117 t/h | -50～3000 t/h | P1/P2 过程量 |
| feedwater_temperature | 给水温度 | 309 °C | -20～400 °C | P1 过程量 |
| reheat_temperature | 再热蒸汽温度 | 623 °C | -50～800 °C | P1 过程量 |
| working_fluid_temperature | 工质温度 | 435 °C | -50～800 °C | P4 瞬态分析输入 |
| furnace_pressure | 炉膛负压 | -0.05 kPa | -5～5 kPa | P1 过程量 |

金属壁温由温度点提供。原有 main_steam_temperature、main_steam_pressure、oxygen 不再进入这套默认点表；已有数据库记录不删除。

应变变化量只表达相邻有效结果的增量，不是变化率、异常变动识别或疲劳指标；不除以时间间隔。首次启动、跳拍、失败轮、断连或重启、前值无效或极端时返回不可用，不用 0 或旧值补造增量。峰值要求全部对应估算可用，不把缺失结果当作 0。

当前轻量范围只采用已确认的电桥换算、应变增量、由换算应变算出的热应力估算和绝对峰值。原型中的裂纹、蠕变、法兰/汽机诊断、FE 对照，以及未确认的总/机械应力分解和许用/屈服比不因点数扩容而自动加入，也不创建待实现的占位通道。页面上的热应力明确标为估算，不冒充实测。

## 3 配置与验证边界

- Modbus 上限为 8，OPC UA 上限为 222（修复轮18）；派生项容量上限 256，实际 25 项。
- Modbus计划轮询及OPC UA请求采样/发布周期为1秒，通知按变化接收；批次计算、推送与完整组归档以终版为准。
- 255个可查询量不是每秒255行原始采样；按实收及变化归档，不复制静止值。开发预算10 GiB，一年容量按终版实测验收。
- 验证默认配置节点与信号一一对应、满 222 个 NodeId 接收、8 路 Modbus 同时接收、派生计数、正常场景极值以及应变增量的符号/断续语义。
