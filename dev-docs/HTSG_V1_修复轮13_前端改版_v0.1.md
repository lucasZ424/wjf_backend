## 2. 改动

- **写入目标（`htsg/archive_router.py`）：** 路由器记下“上一组在等待”：临时主写的判断让组等待时置位，组被接收或正常路由时清除；此时 `target` 为 `UNKNOWN`。只供页面读，路由判断不读它，写入与停机不变。原有的 `archive.health.active_target` 在第6节的收尾里删去。
- **协商约束说明（`htsg/config.py`）：** 四条 OPC UA 协商约束的说明改中文；它们既出现在自检页，也出现在配置校验的报错里。
- **默认标题与配置（`htsg/research_config.py`、`config/research-sim.json`、`config/production.base.json`）：** 默认标题“HTSG 锅炉高温应变监测”；模拟现场标题“HTSG 660 MW 锅炉高温应变监测（模拟数据）”（第17.5节的例外）；通道名“热应力研究估算”改为“热应力估算”，“Bridge 原始信号”改为“电桥原始信号”。`basis` 等不上页面的说明未改。
- **快照（`htsg/static/stream.js`）：** 整份接收时一并取 `archive_target`；校验不通过的说明改中文。
- **回溯记录（`htsg/static/replay.js`）：** 页面上的质量与结果状态写中文（良好、不良、不确定、未取得、已算出、不可用）；CSV 仍写原代码，便于与数据库对账，只把原来的“·”改成括号。
- **页面（`htsg/static/app.js`、`style.css`、`index.html`）：**
  - 用语：按第17.5节逐处改；登录页、页头、页脚去掉英文装饰行和“科研”“模拟”；通信日志的原因、管理操作记录的操作与结果写中文，日志原因旁仍附原代码。
  - 位数：读数按第17.6节的单位位数显示；表外单位按 `ui.precision`；只在浏览器里格式化。
  - 自检页：写入目标读 `archive.target`；新增“磁盘占用”（两卷的占用率、剩余、总量、读取时刻与判定线），某卷读不到时写“无法读取”。
  - 提示条：快照的写入目标为应急库或等待写入时，每页提示。
  - 读取：自检页与通信页的健康读取同一时间只一个，超过 `ui_poll_timeout` 放弃，进入页面时重新读取并丢弃旧答复；后端换了运行 ID 时重读一次 ui-config，配置标识变了就一直提示刷新；绘制出错时连接徽标变红并提示，下一次画成功即清除。
  - 显示：两张图按整分钟（回溯图按窗口自选步长，超过一天带日期）标刻度；回溯图随窗口宽度重画，不重新查询；过滤时已选通道不隐藏；`.scroll` 里的表头吸顶；徽标不折行；页面直属卡片之间留 16 像素；内容没变的表格不重写；鼠标移动的重画合并到每帧一次；刷新后停在当前页，退出后回到总览；窗口长度旁显示换算值；后端连不上时写“连不上后端服务”。
- **现行文档里的页名：** 根目录 README、交付记录、模拟现场使用说明、实施方案（第5行描述10-23基线的那句是历史，不改）改为新页名；`模拟通道分配.md` 的类别名改为“热应力估算”。执行记录、各修复轮记录、审核文档是历史记录，不改。
